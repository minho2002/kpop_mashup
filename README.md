# K-POP 코드 진행 기반 발매연도 예측 & 매쉬업 추천 대시보드

코드 진행(화성 구조)만으로 K-POP 곡의 발매연도를 예측할 수 있는지 검증하고, 이를 실제 매쉬업 제작에 쓸 수 있는
코드 진행 검색·추천 도구로 확장한 개인 프로젝트입니다. 가사·멜로디·음원은 전혀 사용하지 않고, 코드/스케일
디그리/기능화성(T-S-D)만으로 분석합니다.

**🔗 지금 바로 써보기:** https://kpopmashup-csig6qeniae7krhtxgk5mz.streamlit.app/

(무료 서버라 12시간 이상 방문자가 없으면 잠자기 상태가 됩니다 — 처음 접속하면 20~30초 정도 깨어나는 시간이
걸릴 수 있습니다.)

## 이 사이트에서 할 수 있는 것

- **발매연도 예측 (머신러닝)** — 화성 피처만으로 K-POP 곡의 발매연도를 회귀 예측합니다. 여러 차례의 성능
  개선 실험을 거쳐 5-fold 교차검증 기준 R² 0.7 내외까지 끌어올렸습니다.
- **신곡 예측 체험** — 원하는 곡의 코드 진행을 직접 입력하면, 그 진행이 몇 년도 스타일에 가장 가까운지
  실시간으로 예측해 줍니다.
- **비슷한 코드 진행 찾기** — 매쉬업할 곡을 찾을 때 쓰는 기능입니다. 새 곡의 코드 진행을 입력하면 같은
  파트(코러스는 코러스끼리, 벌스는 벌스끼리)만 비교해서 진행·기능화성·템포가 가장 비슷한 기존 곡을
  숫자 랭킹으로 추천합니다.
- **코드 패턴 검색** — SQL의 `LIKE`처럼, "T/S/D가 TTSD인 코러스" 같은 정확한 패턴으로 곡을 필터링해서
  전체 코드 구조를 표로 쭉 보여줍니다. 일치한 구간은 색으로 강조되고, 2박/4박 기준이 다른 곡까지
  변환해서 찾아줍니다.

## 내 곡으로 직접 테스트해보기

1. 테스트하고 싶은 곡의 오디오 파일을 [Moises](https://moises.ai) 같은 코드 인식 앱에 업로드합니다.
   Moises의 **Chord Detection** 기능을 켜면 곡 재생에 맞춰 코드가 자동으로 표시되고, 화면 하단에서
   키(조성)도 함께 확인할 수 있습니다 (무료 계정은 곡의 첫 1분까지만 인식됩니다 — 인트로~코러스 정도는
   충분히 확인 가능합니다).
2. Moises가 표시한 코드를 8마디 단위로 받아 적습니다. 코드가 마디마다 1개씩 바뀌면 "4박 기준", 마디 안에서
   2번씩 바뀌면 "2박 기준"입니다.
3. 아래 "파트(섹션) 구분하는 법"을 참고해서, 곡을 인트로/벌스/코러스 등 구간으로 나눕니다.
4. 이 사이트의 "신곡 예측 체험" 또는 "비슷한 코드 진행 찾기" 페이지에서 곡 정보(키, BPM 등)를 입력하고,
   "섹션 추가하기"로 받아 적은 구간을 하나씩 넣습니다 (파트 종류와 2박/4박 여부 선택).
5. 예측하기 또는 검색하기 버튼을 누르면 결과가 나옵니다.

키와 BPM은 Moises 화면에도 표시되지만, 정확도가 애매하면 직접 듣고 확인하는 것을 추천합니다.

## 파트(섹션) 구분하는 법

섹션을 추가할 때마다 어떤 파트인지 골라야 하는데, 처음이면 헷갈릴 수 있어서 정리했습니다. 곡을 처음부터
들으면서 아래 순서대로 어디에 해당하는지 판단하면 됩니다 (모든 곡에 전부 있는 건 아니고, 곡마다 순서나
구성이 다를 수 있습니다).

| 파트 | 보통 이렇게 들립니다 |
|---|---|
| `intro` | 곡이 시작되는 부분. 보컬 없이 악기만 나오거나, 짧은 훅만 나오는 경우가 많습니다. |
| `verse` (벌스, 1절/2절) | 멜로디가 비교적 잔잔하고, 이야기하듯 가사를 풀어나가는 구간. 후렴보다 힘이 약합니다. |
| `pre-chorus` (프리코러스) | 벌스와 코러스 사이에서 긴장감을 쌓는 짧은 구간. 코드가 잦아지거나 멜로디가 점점 올라가면서 "이제 후렴이 나오겠다"는 느낌을 줍니다. |
| `chorus` (코러스, 후렴) | 곡에서 가장 강력하고 여러 번 반복되는 부분. 보통 제목이나 핵심 가사가 여기서 나오고, 노래방에서 다 같이 따라 부르는 부분이 대부분 여기입니다. |
| `post-chorus` | 코러스가 끝난 직후 짧게 붙는 훅/애드립 구간. 코러스와 이어지지만 가사·멜로디가 조금 다릅니다. |
| `bridge` (브릿지) | 곡 후반부(보통 2번째 코러스 이후)에 한 번만 나오는, 분위기가 확 달라지는 구간. 조성이 바뀌거나 잔잔해졌다가 다시 고조되는 경우가 많습니다. |
| `rap` | 랩으로 진행되는 구간. |
| `build-up` (빌드업) | 다음 구간(주로 코러스나 드롭)으로 넘어가기 직전, 긴장감만 쌓는 아주 짧은 전환 구간. 드럼롤이나 효과음이 들어가기도 합니다. |
| `break-dance` | 보컬 없이 안무/퍼포먼스 위주로 악기만 나오는 구간. |
| `break-down` (브레이크다운/드롭) | 갑자기 소리가 확 빠졌다가 다시 터지는 구간. |
| `outro` | 곡이 마무리되는 부분. |

**팁**

- `verse1`/`verse2`, `chorus1`/`chorus2`/`chorus3`처럼 번호가 붙은 항목은 같은 파트가 곡 안에서 여러 번
  나올 때 순서를 구분하기 위한 것뿐입니다. 이 사이트는 검색·비교할 때 `verse1`과 `verse2`, `chorus1`~`chorus3`를
  전부 같은 파트로 묶어서 처리하므로, 번호를 정확히 맞추지 못해도 결과에 큰 영향은 없습니다. 헷갈리면 그냥
  번호 없는 `verse`/`chorus`를 선택해도 됩니다.
- 애매한 구간은 가장 비슷하다고 생각되는 파트를 고르면 됩니다. 파트 선택은 참고용 분류일 뿐, 코드/도수/T·S·D
  값 자체가 예측·검색의 핵심입니다.
- `intro-chorus`는 인트로에서 곧바로 코러스 멜로디/코드를 미리 들려주는 구성일 때 사용합니다.

## 데이터 범위와 한계 (중요)

- 발매연도 **2012~2026년**의 K-POP 곡 약 260곡(3세대~4세대, 걸그룹 위주 · 일부 보이그룹)의 코드 진행을
  8마디 단위로 직접 채보한 데이터입니다. **이 범위를 벗어난 시기의 곡이나 K-POP이 아닌 장르**를 넣으면
  예측·유사도 결과의 신뢰도가 낮아집니다.
- 코드/도수/T-S-D만 보고 비교하므로, 같은 코드 진행이라도 편곡·리듬·보컬 멜로디가 완전히 다른 곡이 함께
  추천될 수 있습니다. 최종 매쉬업 여부는 직접 들어보고 판단하는 걸 권장합니다.
- "신곡 예측 체험"의 발매연도 예측은 어디까지나 데이터에 담긴 260곡의 화성적 경향을 반영한 결과이며,
  실제 발매연도를 맞히는 것이 아니라 "코드 진행이 어느 시대 스타일에 가까운가"를 보여주는 참고용 지표입니다.

## 페이지 구성

| 페이지 | 설명 |
|---|---|
| 개요 | 연구 가설, 진행 현황, 데이터 분포 |
| 사전지식 (음악 이론) | 피처가 근거한 음악 이론 개념 정리 |
| EDA | 화성 피처의 시대별 분포 탐색 |
| 모델 성능 여정 | 실험 1~5 성능 변화, 시간분할 vs K-fold 교차검증 비교 |
| 피처 중요도 | 순열 중요도 기반 피처 랭킹 |
| 곡별 분석 (레트로/트렌디) | 아티스트별 실제연도 ↔ 예측연도 비교 |
| 가수·곡 검색 | 아티스트 검색 + 곡별 피처 기여도 분해 |
| 신곡 예측 체험 | 코드 진행을 직접 입력해 발매연도 예측 |
| 비슷한 코드 진행 찾기 | 매쉬업용 코드 진행 유사도 검색 (파트별 가중치 + 템포 궁합 반영) |
| 코드 패턴 검색 | T/S/D·도수 패턴으로 곡을 필터링하고 전체 코드 구조를 하이라이트로 확인 |

## 로컬에서 직접 실행하기

```bash

pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 자동으로 열립니다.
