# K-POP 코드 진행 기반 발매연도 예측 & 매쉬업 추천 대시보드

코드 진행(화성 구조)만으로 K-POP 곡의 발매연도를 예측할 수 있는지 검증하고, 이를 실제 매쉬업 제작에 쓸 수 있는
코드 진행 유사도 검색 도구로 확장한 개인 프로젝트입니다. 가사·멜로디·음원은 전혀 사용하지 않고, 코드/스케일
디그리/기능화성(T-S-D)만으로 분석합니다.

**🔗 Live demo:** _배포 후 이 자리에 Streamlit Community Cloud URL을 추가하세요_

## 이 프로젝트가 하는 일

- **발매연도 예측 (머신러닝)** — 293곡의 코드 진행을 11개 화성 피처로 변환해 Ridge/Lasso/RandomForest 등으로
  발매연도를 회귀 예측합니다. 5-fold 교차검증 기준 **R² 0.719, MAE 1.61년**까지 개선했습니다.
- **비슷한 코드 진행 찾기 (매쉬업 추천)** — 새 곡의 코드 진행을 입력하면, 같은 파트(코러스·벌스 등)끼리만 비교해
  코드 진행/기능화성/템포(BPM)가 가장 비슷한 기존 곡을 추천합니다. 머신러닝이 아니라 순수 유사도 검색입니다.
- **신곡 예측 체험** — 직접 코드 진행을 입력해 그 곡이 몇 년도 스타일에 가까운지 실시간으로 예측해 봅니다.

## 페이지 구성

| 페이지 | 설명 |
|---|---|
| 개요 | 연구 가설, 진행 현황, 데이터 분포 |
| 사전지식 (음악 이론) | 피처가 근거한 음악 이론 개념 정리 |
| EDA | 화성 피처의 시대별 분포 탐색 |
| 모델 성능 여정 | 실험 1~5 성능 변화, 시간분할 vs K-fold 교차검증 비교 |
| 피처 중요도 | 순열 중요도 기반 피처 랭킹 |
| 곡별 분석 (레트로/트렌디) | 아티스트별 실제연도 ↔ 예측연도 비교 |
| 가수·곡 검색 | 아티스트 검색 + 곡별 피처 기여도 분해 |
| 신곡 예측 체험 | 코드 진행을 직접 입력해 발매연도 예측 |
| 비슷한 코드 진행 찾기 | 매쉬업용 코드 진행 유사도 검색 (파트별 가중치 + 템포 궁합 반영) |

## 데이터

`KPOP MASHUP.xlsx`에 3세대·3.5세대·4세대 걸그룹/보이그룹 총 293곡의 코드 진행을 8마디 단위로 직접 채보한
원자료가 들어 있습니다. `processed/`에는 실험 1~5의 중간 결과 CSV가 들어 있어 "모델 성능 여정" 페이지의
비교 차트에 쓰입니다.

## 로컬에서 실행하기

```bash
git clone <이 저장소 URL>
cd <저장소 폴더>
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501`이 자동으로 열립니다.

## Streamlit Community Cloud로 배포하기

1. 이 저장소를 GitHub 계정에 그대로 push합니다 (아래 "GitHub에 올리기" 참고).
2. [share.streamlit.io](https://share.streamlit.io)에 GitHub 계정으로 로그인합니다.
3. "Create app" → "Yup, I have an app" → repository/branch/entrypoint에 각각 이 저장소, `main`,
   `app.py`를 입력합니다.
4. "Deploy"를 누르면 몇 분 안에 `https://<subdomain>.streamlit.app` 형태의 공개 URL이 생성되고, 이 링크만
   있으면 누구나 브라우저에서 바로 접속해 쓸 수 있습니다 (설치 불필요).
5. 이후 이 GitHub 저장소에 push할 때마다 배포된 사이트도 자동으로 갱신됩니다.
